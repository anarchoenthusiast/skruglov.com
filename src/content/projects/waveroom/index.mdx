Remote recording in the browser comes with a specific set of constraints: local capture, codec differences across devices, latency, dropped connections, post-processing. Every UX decision on Waveroom had to account for one of those. I was Principal Designer.

Two things made this project interesting. The first was the UX itself — building flows that felt simple for a podcaster while hiding a lot of technical complexity underneath. The second was the design system: Waveroom needed to work across web, iOS, and desktop, and multimedia interfaces have edge cases that generic component libraries do not cover. I built the system from the ground up for that.

The result was a product with a consistent cross-platform UI, a brand platform built from scratch, and a design foundation the team could actually work with as the product grew.
